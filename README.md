# 图片透视校正 Web 工具 · Perspective Corrector

纯前端、零后端的图片透视/倾斜自动校正工具，专为**建筑 / 风光**（仰拍歪斜、柱子汇聚）场景设计。

> 部署示例（CloudBase 静态托管）：https://workbuddy-d0gn1j3r38dddc944-1303694139.tcloudbaseapp.com/

## 功能

- **自动校正**：检测图中竖线/横线，估计灭点与相机姿态，自动把"歪掉的柱子"拉直（透视直立）。
- **画引导线微调**：自动结果不满意时，手绘蓝色竖线 / 绿色横线作为约束，实时重算校正。
- **参数面板**：pitch / yaw / roll / FOV 等滑块手动微调，所见即所得。
- **高质量导出**：原分辨率 `warpPerspective`，`INTER_LANCZOS4` 插值，自动裁剪校正产生的黑边。
- **置信度提示**：状态栏显示"共识百分比 / 偏差角度"，一眼判断该不该信自动结果。

## 算法

经典计算机视觉流水线（无模型、纯浏览器运行，隐私友好、零下载）：

1. `Canny` + `HoughLinesP` 线段检测（两轮阈值取并集，提升召回）
2. 窄角度聚类（竖 78°–102°、横 ±12°）+ RANSAC 稳健灭点估计
3. 相机旋转模型：单应 `H = K · Rᵀ · K⁻¹`（`K` 由 FOV 与图像尺寸构造）
4. 双路径：竖线汇聚 → 透视直立（灭点姿态）；竖线近平行 → 稳健 2D 旋转（抗离群线 + ≤1.2° 死区，防误转）
5. 「共识 ≥ 60% 且偏差 > 阈值才校正」的启发式门控，识别"线不够 / 方向乱"的场景

## 使用

直接打开 `index.html` 即可（需联网加载 `opencv.js`）。上传图片后：

1. 点「自动校正」——竖线被识别并拉直；
2. 不满意 → 切到原图面板「画引导线」；
3. 点「参数」打开面板微调；
4. 点「下载」导出校正成品。

## 已知限制

- 无直线的场景（纯风景、人像）无法自动校正，需手绘引导线。
- 广角仰拍校正后画面四角会露黑（warp 必然结果），目前仅自动裁矩形黑边，不补角。
- 当前为扎实的「经典 CV 基线」，非学习型 SOTA（如 DeepLSD / 扩散模型精修）。
